# Google Cloud & Terraform Ignore Rules Reference

This document provides ready-to-use snippets for Google Cloud Platform environments and Terraform workflows.

---

## Google Cloud Security Patterns

### Service Account Credentials
Never commit JSON keys generated by `gcloud iam service-accounts keys create`:
```gitignore
# GCP Service Account Keys
*.json
!package.json
!tsconfig.json
!composer.json
!*.schema.json
!manifest.json
*key*.json
*credentials*.json
*service-account*.json
```

### Application Default Credentials
```gitignore
# Google Application Default Credentials
application_default_credentials.json
.config/gcloud/
```

## `.gcloudignore` Standard Specification

Deployments with `gcloud` should respect `.gcloudignore` to prevent uploading git directories, local caches, and terraform state:

```text
# This file specifies files that are *not* to be included in gcloud deployments.
.gcloudignore
.git
.gitignore

# HashiCorp Terraform state and provider caches
.terraform/
*.tfstate
*.tfstate.*
*.tfvars
*.tfplan

# OS / Editor Files
.DS_Store
.idea/
.vscode/

# Local logs and scripts
*.log
crash.log
```
